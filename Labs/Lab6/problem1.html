Prime Numbers Finder!

Write the app to prompt accepting for a positive integer number

  • If the entered text is not a positive integer,then the web will keep asking for an integer until a valid positive integer is entered.
  • If the entered text is a positive integer,them the web app will add into a list of prime numbers.

Note:

  1. You may want to use loop with label
  2. You may want to use array with push function
