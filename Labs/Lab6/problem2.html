Statistics Calculator!

Write the webapp to accept positive integers until the user enters a negative number.

  • If the entered text is not a positive integer, the web will keep asking for an integer until a valid one is entered.
  • If the user enters a negative number, the webapp will display the statistics (average, minimum, maximum).

Note:

  • You need to implement the logic to check whether the input is a positive integer or not.
  • You need to implement the logic to calculate the average, minimum, and maximum.
