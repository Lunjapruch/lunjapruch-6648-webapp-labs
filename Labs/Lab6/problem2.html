Statistics Calculator!

Write the webapp to accept positive integers until the user enters a negative number.

  • If the entered text is not a positive integer,then the web will keep asking for an integer until a valid positive integer is entered.
  • If the user enters a negative number, the webapp will show the statistics (average, minimum, maximum) of all entered positive integers.

Note:

  1. You need to implement the functions to check wheather an entered text is positive intreger or not and whether an entered text is a negative integer or not
  2. You need to implement the function to compute average, min, and maximum of a list of intregers.
